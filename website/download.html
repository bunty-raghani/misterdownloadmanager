The browser extension

It hands your browser's downloads to MDM with their cookies, adds Download with Mister Download Manager to the right-click menu and puts a Download video button over videos.

Firefox (and Zen, LibreWolf): one click from its add-ons store, and Firefox keeps it up to date.

Chrome, Edge, Brave, Opera and Vivaldi: one click from the Chrome Web Store, and the browser keeps it up to date. Edge first asks to allow extensions from other stores.

Can't use a store? It comes with the app, in its extension folder, and as its own download for Chromium browsers (.zip: unzip, then Load unpacked on the browser's extensions page with Developer mode on). The step-by-step guide shows each browser.

Install in three steps

  1. Download setup.exe above and run it. Windows may ask whether to allow it: the installer isn't code-signed yet, so choose More info → Run anyway.
  2. Pick your language and keep Set up browser integration ticked.
  3. Start Mister Download Manager from the Start menu, then download your first file.

With WinGet, Windows' package manager: in a terminal, the first line installs MDM and the second updates it.

winget install AhmedNefzaoui.MisterDownloadManager
winget upgrade AhmedNefzaoui.MisterDownloadManager

On Linux or a Mac

Linux: install the .deb with sudo apt install ./<file>.deb (Debian, Ubuntu, Mint) or the .rpm with sudo dnf install ./<file>.rpm (Fedora), and the packages bring what MDM needs. Or make the AppImage executable (chmod +x) and run it. MDM connects itself to your browsers at each start; then add the extension from your browser's store, above. More in the help.

macOS: open the .dmg and drag Mister Download Manager to Applications, then right-click it and choose Open the first time.

Linux isn't experimental any more, since version 0.5.0. GNOME, KDE Plasma, Xfce and Cinnamon are checked window by window, with the tray and Dark Mode support, in Wayland sessions too, and the .deb and .rpm in clean Ubuntu 24.04, Debian 12 and Fedora 45 systems. What's left: the Flatpak Firefox isn't checked yet, and screen readers (Orca) don't read MDM's windows on Linux yet. macOS stays experimental. Windows, Mac and Linux

Check your download

  1. From the release, download SHA256SUMS.txt, the SHA-256 checksum of every file, and its signature, SHA256SUMS.txt.sig.
  2. Get your file's checksum: on Windows with certutil -hashfile file SHA256, on macOS and Linux with shasum -a 256 file. It must match the file's line in SHA256SUMS.txt.
  3. To be sure the list itself is ours, check its signature with GnuPG: import MDM's release key, then run gpg --verify SHA256SUMS.txt.sig SHA256SUMS.txt. It should report a Good signature from the key 5826 D399 249D E856 EA08 7D80 2E29 3C28 E8A6 9D74.

Every file is built from the public source by GitHub Actions; the build logs are on GitHub.

If Windows or an antivirus warns

The installer isn't code-signed, and each new version is new to Windows, so SmartScreen may show Windows protected your PC until enough people have run it. Choose More info, check that the file is MisterDownloadManager-{{VERSION}}-setup.exe, then Run anyway.

A few antivirus programs, mostly machine-learning engines, flag new installers they have rarely seen. On VirusTotal, a handful of small engines flagging the setup while the big ones stay clean is usually a false positive. If the checksum matches, it is the file we published; if something still looks wrong, tell us on GitHub. More in Troubleshooting.
